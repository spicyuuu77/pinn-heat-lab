# 一维热传导方程的 PINN 学习项目

本项目用于从基础开始学习物理信息神经网络（PINN），依次独立实现标准 PINN 与混合求导 PINN，并通过解析解检查计算结果。同时练习环境管理、代码组织、实验记录和 Git 版本管理。

## 项目目标

参考仓库：[PINN solves the one-dimensional heat conduction equation](https://github.com/yydjya/PINN-solves-the-one-dimensional-heat-conduction-equation)。

求解以下一维热传导问题，第一轮固定热扩散系数为 `α = 1`：

$$
\frac{\partial u}{\partial t}=\alpha\frac{\partial^2u}{\partial x^2},\qquad x\in[-1,1],\quad t\in[0,1]
$$

初始条件与边界条件为：

$$
u(x,0)=\sin(\pi x),\qquad u(-1,t)=u(1,t)=0
$$

用于验证结果的解析解为：

$$
u(x,t)=e^{-\alpha\pi^2t}\sin(\pi x)
$$

计划先使用自动求导完成标准 PINN，再实现时间自动求导与空间局部多项式求导相结合的混合 PINN。最终在相同问题和可比较的训练设置下，记录两种方法的误差与耗时。

参考代码中已发现解析解、评估参数传递和混合求导实现等问题，复现时需要逐项修正。正确性以方程、初边值条件和经过验证的解析解为依据。

| 评估网格 | 空间 201 点 × 时间 101 点，共 20301 点；不使用训练中的随机样本 |

### 评估结果

| 指标 | 结果（约） | 首轮目标 | 当前判断 |
| --- | --- | --- | --- |
| 全时空 MAE | 0.04892051 | 暂作对照记录 | 不据此单独判断达标 |
| 全时空相对 L2 | 0.60275674，即 60.28% | ≤ 0.05，即 5% | 未达标 |
| 初始条件最大绝对误差 | 0.68380123 | ≤ 0.05 | 未达标 |
| 左边界最大绝对误差 | 0.39136362 | ≤ 0.05 | 未达标 |
| 右边界最大绝对误差 | 0.38804954 | ≤ 0.05 | 未达标 |

设评估网格上的误差为 `e = u_pred - u_exact`，则：

- MAE 为 `mean(abs(e))`，是绝对误差的平均值，不是百分比。
- 整体相对 L2 为 `sqrt(sum(e**2) / sum(u_exact**2))`，先分别求和再相除，避免逐点除以零或极小的解析解。
- 初始条件误差取 `t = 0` 的 201 个空间点上的最大绝对误差。
- 左右边界误差分别取 `x = -1`、`x = 1` 的 101 个时间点上的最大绝对误差；边界真值为零。

所有最大误差均在上述有限评估网格上计算，不是整个连续区域上的严格误差上界。

## 混合 PINN：空间算子验证与 5000 步基线

记录整理于 2026-10-27。空间求导和混合残差检查由学习者完成，分别保存在 `check_spatial.py`、`check_hybrid.py`；训练脚本为 `train_hybrid_demo.py`。以下训练结果来自终端截图及保存文件的独立读取评估，未为更新文档而重新训练。

### 求导与采样检查

均匀网格上使用三点中心差分，它对应三点二次局部多项式的二阶求导模板。矩阵 `D2` 的形状为 `(N-2, N)`：输入全部 N 个点的函数值，输出 N−2 个内部点的二阶导数，端点通过边界损失约束。

`check_spatial.py` 使用 float64 检查常数、一次和二次函数，结果分别接近 0、0、2；N=200 时最大多项式误差约为 `3.64e-12`。对 `sin(πx)` 的内部二阶导数检查如下：

| 网格点数 N | 矩阵形状 | 最大绝对误差（约） |
| --- | --- | --- |
| 50 | `(48, 50)` | 0.01350905 |
| 100 | `(98, 100)` | 0.00331203 |
| 200 | `(198, 200)` | 0.00081987 |

网格加密后误差约缩小至四分之一，符合中心差分二阶精度的预期。这里验证的是空间算子，不是网络求解误差。

`check_hybrid.py` 使用 N=50、三个固定时间 0、0.1、0.5 和正确解析解检查混合残差。每组空间点共享同一时间，对展平后的逐点时间输入求 `u_t`，将预测整理为 `(n_times, N)` 后计算 `Uxx = U @ D2.T`，再构造 `Ut[:, 1:-1] - alpha * Uxx`。三个时间的最大残差约为 `0.013509`、`0.0050349`、`0.000097156`，与空间差分的离散误差及解析解的时间衰减一致。

构造矩阵时曾将 `D2 / h**2` 错放在填行循环内，导致反复缩放、浮点溢出及训练出现 NaN。现已将缩放放在填完整个矩阵之后，并在训练前检查矩阵所有元素有限。

## 时间采样控制实验：固定空间位置与残差点数

记录整理于 2026-10-27。本轮针对“标准方法为何从原来的约 6.91% 变为分组采样下的 11.24%”做一次有明确变量的检查。新建 `train_sampling_demo3.py`，保留已有代码和实验文件，实际运行一次新的 5000 步标准 PINN 训练。

### 实验设计

保留 N=50 的空间网格及其四份副本，每步仍有 200 个网络输入点、192 个内部 PDE 残差点。网络结构、初始化种子 42、CPU float32、初边值采样、损失权重、优化器、学习率调度、5000 步训练及独立评估网格均保持一致。

- `time_sampling = "grouped"`：每份空间网格共享一个随机时间，与上一轮标准对照一致。
- `time_sampling = "independent"`：给每个 PDE 输入点分别抽取 [0,1) 上的时间，空间坐标保持不变。

为避免改变 PDE 抽样数量后连带改变初始点和边界点，脚本保留基线每步四个时间值的全局随机数消耗，并用独立 `torch.Generator`（种子 1042，即网络种子加 1000）生成新增的逐点时间。这是一次固定网络种子的时间采样方案实验，不是种子 43 的重复实验。

两种模式先各运行 10 步做控制检查：初始网络参数相同，所有 PDE 空间坐标及初始、左右边界样本逐点相同；分组模式的前 10 步分项损失与已保存的标准对照完全一致。新的完整训练只运行逐点独立时间模式，原来的分组结果直接复用。

本实验仅使用标准 PINN：时间和空间导数均逐点自动求导，因此同一行可以包含不同时间。混合 PINN 的空间差分需要同一时刻的空间分布，不能直接套用这种逐点时间采样；新脚本限制方法为标准 PINN。

### 结果

| 指标 | 分组时间基线 | 逐点独立时间 | 目标与本轮判断 |
| --- | --- | --- | --- |
| 每步内部残差点数 | 192 | 192 | 保持一致 |
| 全时空 MAE | 0.01393286 | 0.00760276 | 下降 |
| 全时空相对 L2 | 11.2374% | 6.2038% | ≤5%，尚未达标 |
| 初始条件最大绝对误差 | 0.04880244 | 0.02809829 | ≤0.05，达标 |
| 左边界最大绝对误差 | 0.08785912 | 0.04955400 | ≤0.05，达标 |
| 右边界最大绝对误差 | 0.07834807 | 0.04357599 | ≤0.05，达标 |

本轮训练循环耗时 48.4814 秒，作为运行记录保存，不用于比较两种求导方法的速度。已重新加载新权重，在共同的 201×101 评估网格上重现五项误差，并检查四项损失各 5000 条、模型参数均有限。保存的初始切片与损失图已打开检查。

在固定空间位置、残差点数及初边值样本的情况下，仅改变 PDE 时间抽样方案，整体相对 L2 降低约 5.03 个百分点，且初边值三项最大误差均通过阈值。这支持“每步只有四个独立时间值限制了本配置的训练”这一解释，不能把此前误差上升直接归因于标准自动求导实现出错。仍是单次控制实验，尚不能推广为所有问题和随机样本下都改善相同幅度。

本轮恢复并略优于早期随机空间采样基线约 6.91% 的整体误差，但早期基线每步只有 100 个内部点，不能将二者的小幅差异单独归因于某一因素。目前标准 PINN 在本轮评估网格上通过全部初边值阈值，整体相对 L2≤5% 仍未达到；混合方法没有在本轮追加训练。
